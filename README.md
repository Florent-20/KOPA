## 📖 About the Project

**KOPA** is a movie website currently under development. The project focuses on creating an attractive and easy-to-navigate interface where users can **browse movies** and **explore movie-related content**.

🎯 **The goal:** to provide users with a simple and enjoyable movie discovery experience.

## 🚀 Getting Started

To view the website locally:

**1.** Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

**2.** Open the project folder.

**3.** Open `index.html` in your web browser. 🍿

No installation or build tools needed. Just a browser!
